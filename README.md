# CDA — сайт фигурок ручной работы

Статический сайт по согласованным макетам Figma: 1440 px и 390 px. Изображения и бесплатные шрифты PT / Caveat хранятся локально. Все кнопки заказа ведут в Телеграм автора.

Для просмотра достаточно статического HTTP-сервера. Сборка и установка зависимостей не требуются. GitHub Pages публикует корень ветки main.
