# Тихая глина

Концепт вымышленной керамической мастерской Аси. Статический сайт: котики, три жабки и компания жабок-крошек, четыре Смешарика и котик с индивидуальным окрасом по фото. На главной крупные котики обрамляют низкую группу: белый котик, жабка и Ёжик.

Изображения созданы с помощью ImageGen и хранятся локально. Реальные заказы не принимаются, цены ориентировочные. Контакты прежней мастерицы удалены.

Запуск: `python3 -m http.server 8765 --bind 127.0.0.1`. Сборка и установка зависимостей не требуются. GitHub Pages публикует корень ветки main. Шрифты PT и Caveat сохранены вместе с лицензиями.
